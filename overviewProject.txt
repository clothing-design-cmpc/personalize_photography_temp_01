================================================================================
PROJECT OVERVIEW — Isla Serena Private Resort Website
================================================================================

================================================================================
TECH STACK
================================================================================

Frontend       : Next.js 16.2.x (App Router, Turbopack dev server)
Language       : JavaScript (JSX) — no TypeScript
Animations     : Motion 12.x (formerly Framer Motion) + GSAP 3.15.x

Images         : next/image with Unsplash remote patterns
Node.js        : 24.x (Active LTS) recommended

================================================================================
DATA MODELS
================================================================================

rooms.json
  id, name, tagline, description, price (PHP), currency, priceLabel,
  capacity, size (sqm), rating, reviewCount, image (Unsplash URL), features[], category

amenities.json
  id, name, icon (emoji), description

services.json
  tabs[]: { id, label, services[]: { id, name, icon, description, duration } }

testimonials.json
  id, name, location, stayType, rating, quote, avatar (Unsplash URL), date

faq.json
  id, question, answer

================================================================================
API ROUTES
================================================================================

POST /api/booking
  Body: { checkIn, checkOut, guests, roomType }
  Response: { success, message }
  Note: Connect to email service via BOOKING_EMAIL env var

POST /api/contact
  Body: { firstName, lastName, email, phone, inquiryType, message }
  Response: { success, message }
  Note: Connect to email service via CONTACT_EMAIL + RESEND_API_KEY env vars

================================================================================
ANIMATION SYSTEM
================================================================================

Library        : Motion 12.x (import from 'motion/react')
                 Note: package was 'framer-motion', now renamed to 'motion'
                 Both packages work; new installs should use 'motion'

GSAP           : 3.15.x — now 100% free including all plugins (SplitText, MorphSVG, etc.)
                 Use @gsap/react useGSAP() hook for proper React cleanup

Motion Variants (lib/animations.js):
  fadeIn, fadeInSlow, slideUp, slideUpFast, slideInLeft, slideInRight,
  scaleUp, scaleBounce, containerVariants, cardContainerVariants,
  childVariants, cardChildVariants, pageTransition

Parallax:
  - Desktop: requestAnimationFrame scroll handler (useParallax hook)
  - Mobile: disabled (background-attachment: scroll in mediaQueries.css)
  - Respects prefers-reduced-motion (parallax-utils.js check)

Scroll Animations:
  - useIntersectionObserver hook — triggers Motion animate on viewport entry
  - One-time trigger (unobserves after first intersection)
